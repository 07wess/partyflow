# 🧩 PartyFlow Chrome Eklentisi (Teleparty Modu)

Bu eklenti, **Netflix**, **Disney+** ve **Prime Video** üzerindeki filmleri partnerinizle birebir senkronize izlemenizi sağlar.

## 🚀 10 Saniyede Chrome'a Yükleme

1. Google Chrome veya Brave / Edge tarayıcınızı açın.
2. Adres çubuğuna şunu yazıp Enter'a basın:
   `chrome://extensions`
3. Sağ üst köşedeki **"Geliştirici Modu" (Developer Mode)** anahtarını açın.
4. Sol üstte çıkan **"Paketlenmemiş Öğe Yükle" (Load unpacked)** butonuna tıklayın.
5. Bu klasörü seçin:
   `C:\Users\W3SLEY\.gemini\antigravity\scratch\socket-app\extension`

## 🎬 Nasıl Kullanılır?

1. PartyFlow sunucunuz çalışırken (`npm start`), Netflix veya Disney+'ı açın.
2. Tarayıcının sağ üstündeki yapboz simgesinden **PartyFlow** eklentisine tıklayıp oda adınızı (varsayılan: `ask-yuvasi`) kontrol edin.
3. Netflix sayfasının sağ üstünde yeşil **"🍿 PartyFlow: ask-yuvasi"** rozetini göreceksiniz.
4. Artık sen veya sevgilin filmi durdurduğunda, sardığında veya başlattığında iki taraf da anında aynı saniyeye kilitlenir!
